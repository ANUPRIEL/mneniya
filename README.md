# Мнения — полнофункциональный интерактивный прототип

## Как запустить
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Интернет и сервер не требуются.

## Что работает
- онбординг;
- главная лента и фильтры;
- отдельная страница вопроса;
- отправка анонимного мнения;
- жалоба на вопрос;
- создание вопроса;
- создание исследования;
- кабинет автора;
- жизненный цикл исследования;
- публикация результата или завершение без публикации;
- профиль «Ваш вклад»;
- уведомления;
- настройки и приватность;
- локальное сохранение в браузере через localStorage;
- адаптация под мобильный экран.

## Структура
- `index.html` — точка входа;
- `styles.css` — визуальная система;
- `data.js` — демонстрационные данные;
- `app.js` — навигация, сценарии и хранение данных.

Это клиентский MVP-прототип без настоящего сервера, авторизации и общей базы данных.
